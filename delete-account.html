계정 및 데이터 삭제 안내

잔액 관리 가계부 · 최종 수정일: 2026년 10월 10일

"잔액 관리 가계부" 앱에서 구글 계정으로 로그인해 사용한 경우, 아래 방법으로 계정과 서버에 저장된 모든 데이터를 직접 삭제할 수 있습니다.

1. 앱에서 직접 삭제하기 (가장 빠른 방법)

삭제 단계
  1. 앱을 열고 화면 우측 상단의 프로필 아이콘을 누릅니다.
  2. 계정 창에서 "내 정보 모두 삭제" 버튼을 누릅니다.
  3. 확인 창에 삭제를 입력하고 "삭제하기"를 누릅니다.
  4. 보안을 위해 구글 재인증 창이 나타나면 같은 구글 계정으로 한 번 더 확인합니다.

삭제는 즉시 처리되며 되돌릴 수 없습니다.

2. 앱을 이미 삭제했거나 앱에서 삭제할 수 없는 경우

아래 이메일로 삭제를 요청해 주세요.

  • 로그인에 사용한 구글 계정 이메일 주소에서 메일을 보내주세요. (본인 확인용)
  • 제목에 "계정 삭제 요청"이라고 적어주세요.
  • 요청 확인 후 7일 이내에 삭제하고 완료 여부를 회신해 드립니다.

3. 삭제되는 데이터와 보관되는 데이터

구분내용처리
계정 정보구글 로그인으로 제공된 이름, 이메일 주소, 프로필 사진, 사용자 ID삭제
가계부 기록직접 입력한 항목명, 금액, 메모, 날짜 등 서버(Firebase Firestore)에 저장된 기록 전체삭제
이 기기에 저장된 기록앱을 사용 중인 기기 안의 캐시 데이터앱에서 삭제 시 함께 삭제
추가 보관: 개발자는 삭제된 데이터를 별도로 보관하거나 백업하지 않습니다. 서비스 제공업체인 Google(Firebase)의 인프라에서는 자체 정책에 따라 시스템 백업에서 일정 기간 뒤에 완전히 지워질 수 있으며, 이 기간 동안에도 개발자와 다른 이용자는 해당 데이터에 접근할 수 없습니다.

4. 계정은 유지하고 일부 데이터만 삭제하기

로그인 상태를 유지한 채 필요한 기록만 지울 수도 있습니다.

  • 거래 내역 삭제: 항목을 펼쳐 각 내역 오른쪽의 × 버튼을 누릅니다.
  • 항목 삭제: "항목 관리"에서 항목을 삭제하면 해당 항목의 거래 내역도 함께 삭제됩니다.

5. 로그인 없이 사용한 경우

로그인 없이 사용한 기록은 서버로 전송되지 않고 이용자의 기기에만 저장됩니다. 앱을 삭제하면 모든 기록이 함께 삭제됩니다.
